Backend della Mappa turistica del Prosecco

Accesso riservato

Inserisci la password del backend (variabile ADMIN_PASSWORD nel file .env; predefinita prosecco).

Seleziona un punto di interesse dall'elenco, oppure creane uno nuovo.
I tracciati seguono la rete stradale di OpenStreetMap (OSRM). Le tappe sono id di punti di interesse oppure coordinate "lon,lat".
Seleziona un itinerario.
Foto equirettangolari (2:1), aeree o a terra. I collegamenti creano le frecce per passare da una foto all'altra.
Seleziona una foto 360.

Scale importance code (livelli)

Le scritte compaiono progressivamente avvicinando la camera. Qui si imposta la distanza (in metri) della camera sotto la quale compaiono i livelli 2 e 3; il livello 1 è sempre visibile. Il livello di ciascun luogo si cambia nella scheda del punto di interesse.

Plastico

Mappe sovrapponibili

Riquadro geografico del plastico e delle mappe fornite (le tre mappe GRANDE sono screenshot in Web Mercator con lo stesso inquadramento). Per spostare o scalare le mappe, correggi i quattro bordi.

Attenzione: cambiando il riquadro, il rilievo e la mappa dei colori vanno rigenerati con npm run dati --solo=terreno e --solo=colori (altrimenti restano riferiti al riquadro precedente).

Copia di sicurezza

Scarica o ripristina l'intero contenuto (punti di interesse, itinerari, foto 360, impostazioni). I file multimediali restano nella cartella uploads/.
